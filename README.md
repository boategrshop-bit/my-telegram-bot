# 🤖 Claude Telegram Bot - ระบบจัดการลูกค้า

Bot ช่วยจัดการข้อมูลลูกค้า, บัญชีกำไร-ต้นทุน และวันหมดอายุ ผ่าน Telegram

---

## ✅ สิ่งที่ Bot ทำได้

| พิมพ์อะไร | Bot ทำอะไร |
|---|---|
| "เพิ่มลูกค้า สมชาย 0812345678 แพ็ก 30 วัน 500 บาท" | บันทึกลูกค้าลง Excel |
| "บันทึกรายรับ 2000 ต้นทุน 500 รายการ ค่าสมาชิก" | บันทึกบัญชีลง Excel |
| "ใครหมดอายุสัปดาห์นี้" | แสดงรายชื่อลูกค้าใกล้หมดอายุ |
| "สรุปยอด" | แสดงยอดรวมกำไร ลูกค้าทั้งหมด |
| "หา สมชาย" หรือ "ค้นหา 0812" | ค้นหาลูกค้า |

---

## 🚀 วิธีติดตั้ง (ทีละขั้นตอน)

### ขั้นที่ 1: สร้าง Telegram Bot

1. เปิด Telegram แล้วค้นหา **@BotFather**
2. พิมพ์ `/newbot`
3. ตั้งชื่อ bot และ username (ต้องลงท้ายด้วย `bot`)
4. คัดลอก **Token** ที่ได้รับ เก็บไว้ใช้ทีหลัง

### ขั้นที่ 2: สมัคร Anthropic API

1. ไปที่ https://console.anthropic.com
2. สมัครและเติมเครดิต (เริ่มต้น $5 เพียงพอสำหรับทดสอบ)
3. ไปที่ **API Keys** → สร้าง key ใหม่
4. คัดลอก **API Key** เก็บไว้

### ขั้นที่ 3: Deploy บน Railway (ฟรี)

1. ไปที่ https://railway.app และสมัครด้วย GitHub
2. กด **New Project** → **Deploy from GitHub repo**
3. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub ก่อน (bot.py, requirements.txt, railway.toml)
4. เลือก repo แล้วกด Deploy
5. ไปที่ **Variables** แล้วเพิ่ม:
   ```
   TELEGRAM_TOKEN = (token ที่ได้จาก BotFather)
   ANTHROPIC_API_KEY = (key ที่ได้จาก Anthropic)
   ```
6. Railway จะ restart อัตโนมัติ Bot พร้อมใช้งาน!

### ขั้นที่ 4: ดาวน์โหลดไฟล์ Excel

เนื่องจาก Railway เป็น cloud ไฟล์ Excel จะอยู่บน server
วิธีดาวน์โหลดข้อมูล: พิมพ์ว่า "ส่งไฟล์ excel" (ฟีเจอร์เพิ่มเติม)
หรือใช้ Railway CLI: `railway run python -c "import shutil; shutil.copy('data.xlsx', '.')"`

```

Bot: ✅ เพิ่มลูกค้าสำเร็จ! (ID: 1)
     บันทึก นายสมชาย แพ็กรายเดือน หมดอายุ 2025-06-19

คุณ: ใครหมดอายุใน 3 วัน
Bot: ⚠️ ลูกค้าใกล้หมดอายุภายใน 3 วัน (2 ราย):
     • นายสมชาย (0812345678) - หมด 2025-05-21 (อีก 2 วัน)
     • นางสาวมาลี (0898765432) - หมด 2025-05-22 (อีก 3 วัน)

คุณ: สรุปยอด
Bot: 📊 สรุปภาพรวม
     👥 ลูกค้าทั้งหมด: 15 ราย
        ✅ ใช้งานได้: 12 ราย
        ❌ หมดอายุ: 3 ราย
     💰 รายรับรวม: 45,000 บาท
     💸 ต้นทุนรวม: 15,000 บาท
     📈 กำไรสุทธิ: 30,000 บาท
```

## 💰 ค่าใช้จ่าย

| บริการ | ราคา |
|---|---|
| Telegram Bot API | ฟรี |
| Railway (Hobby plan) | $5/เดือน |
| Claude API | ~$0.003 ต่อการใช้งาน 1 ครั้ง |

**โดยรวมถ้าใช้วันละ 50 ครั้ง ≈ $5 + $4.50 = ~$9.50/เดือน (~330 บาท)**
